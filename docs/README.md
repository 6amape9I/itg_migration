# Docs

Эта папка предназначена для отчётов исполнителя, чек-листов и обратной связи по выполненным инструкциям.

Правило работы:

1. После каждого набора правок добавлять отчёт в `docs/reports/`.
2. В отчёте фиксировать цель, изменения, чек-лист, проверки и вопросы/риски для архитектора.
3. Не хранить здесь generated data, секреты или пользовательские медицинские данные.
